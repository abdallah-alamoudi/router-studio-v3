# Security policy

## Supported status

Router Studio is currently a preview project. Security fixes are welcome, but no production service-level response time is promised.

## Report a vulnerability privately

Please do not disclose vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** action for this repository to create a private security advisory. Include the affected version/commit, impact, reproduction steps, and any safe proof-of-concept details. Do not include real API keys, account data, or other users' personal information.

If private vulnerability reporting is unavailable, contact the repository owner privately through GitHub before public disclosure.

## Scope and safety

Do not test against another person's machine, account, credentials, or live provider. Avoid tests that send paid upstream requests unless the repository owner has explicitly authorized them. Local-only reproducible reports are preferred.
