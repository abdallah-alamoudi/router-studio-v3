# Router Studio offline desktop preview

This is an unsigned Windows x64 preview, not a public release. Extract the entire versioned ZIP, open its folder, and run Install-Desktop.cmd. Review the unsigned-preview notice and type INSTALL after saving work and closing Studio and Codex. No application is closed automatically. Stop the owned local router before an upgrade using Studio's confirmed Stop action.

Installation is per user under `%LOCALAPPDATA%\RouterStudio`; encrypted router data remains under `%LOCALAPPDATA%\Safe8stokenRouter`. Node, PowerShell and .NET are private to the package. Global PATH is unchanged, and first launch downloads nothing. Open `%LOCALAPPDATA%\RouterStudio\Launch-Desktop.vbs`. Startup is opt-in in Settings. Existing legacy router startup is preserved; do not add a second entry. To replace it, disable the legacy launcher yourself after reviewing its target, then select router startup in Settings.

Existing same-user v3 keys, routes, catalog, provider selection, and backups are retained. New users open Settings > First-time router setup, enter the masked Plus key and optional Pro/Full keys, and review setup. This step changes Codex's default connection and starts the router. Save work and close Codex first. Sign out and back in once afterward so Codex inherits local authentication. An occupied router port causes setup to refuse changes. Installation itself sends no generation requests; Test Lab requests require a separate preview and acknowledgement.

An upgrade verifies every packaged file, stores recoverable control-file preimages, and switches its version pointer last. A pending upgrade blocks launch until the installer recovers it. New release versions are immutable; do not reuse a version for different contents. Externally edited recovery files cause a refusal, not an overwrite. Retained old releases enable recovery. Stable helper scripts upgrade when their installed bytes match the verified active release; external edits are refused. Ordinary installation failures restore their preimages. Helpers must retain compatibility with the previous pointer/schema if the installer is interrupted before switching the payload.

To revert Codex to direct settings, use Backups > Restore while Studio is installed and review the existing external-edit guard. To deactivate Desktop, close Studio, stop its router, then run Windows PowerShell with `scripts\Uninstall-Desktop.ps1 -Acknowledge` from the extracted package. Uninstall removes the active pointer and owned startup registry entries and restores matching prior engine files. Add `-RemoveRecoveryFiles` if you also want verified versioned application/runtime files removed. Edited or incomplete releases are preserved for review. Encrypted keys, configuration, history, and control-file preimages remain. Delete retained user data only after making your own backup and deciding you no longer need recovery. No recursive user-data deletion is performed.

Package hashes detect alteration; they are not publisher authentication. Build sources are pinned in runtime-manifest.json. Official provenance: [Node 24.21.0 release and checksums](https://nodejs.org/en/blog/release/v24.21.0), [PowerShell 7.6.6 release and checksums](https://github.com/PowerShell/PowerShell/releases/tag/v7.6.6), [.NET 10 downloads](https://dotnet.microsoft.com/en-us/download/dotnet/10.0). Included runtime license and third-party notices must be redistributed with the package. Reassess patches and advisories before any release.

Clean-machine offline operation, another Windows account, physical display scaling/accessibility, Windows 10, real provider access, and a signed public installer are separate acceptance gates. See RELEASE-CHECKLIST.md. This package must not be promoted as public-ready until those gates are met.
